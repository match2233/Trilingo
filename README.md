# Trilingo — 英语 / 日语 背单词

Windows 11 桌面应用。启动后从桌面的 `词汇英.xlsx`、`词汇日.xlsx` 读取生词，
每天抽题测验，答错的词按 day+1/+3/+7/+15/+30 自动排期复习。

## 启动

* **桌面快捷方式** `Trilingo`（图标为 `trilingo.ico`）
* 或双击 `Trilingo.pyw`
* 排查问题时可运行 `启动(调试).bat`，会保留一个控制台窗口显示日志

## 答题流程

1. 第一行显示**中文意思**
2. 第二行输入单词，**回车**提交
3. 第三行显示结果：
   * **拼写正确** → 显示音标（日语显示**声调几型**），**5 秒后自动**进入下一个
   * **拼写错误** → 显示正确拼写和音标，右下角出现**【下一个】**按钮，**点击后**才继续；
     该词记入错题本

英语每天 7 个新词，日语每天 15 个新词，**同一天不会出现重复单词**。

* 英语：拼写比对忽略大小写、空格与连字符（`walkie-talkie` = `walkie talkie`）
* 日语：汉字形和假名读音都算对，片假名/平假名互通（`カメラ` = かめら）

## 错题复习规则

| 事件 | 行为 |
| --- | --- |
| day0 答错 | 记入错题本，**day+1** 必现 |
| 复习答对 | 推进到下一档：+3 → +7 → +15 → +30 |
| 走完 +30 | 30 天内没有再错，**移出错题本** |
| 中途再错 | **重置回 day0**，重新排期 |

到期的错题会**必然出现**在当天的测验里（排在当日新词之后），主界面按钮上会显示待复习数量。

## 数据库页

以表格显示全部单词的全部信息，英语/日语分页，**点击表头排序**，支持检索。

* 选中一行后在下方修改，点【保存修改】写入
* 人工修改过的内容标记为 `manual`，**不会被自动补全覆盖**
* 【重新读取 Excel】可立即重新同步源文件
* 从 Excel 中删掉的词会标记为“已移除”并停止出题，勾选后可查看，历史记录保留

## 数据来源与自动补全

每次打开应用都会**重新读取两个 xlsx**，把新词并入数据库，并在后台补全缺失内容：

> **工作表范围**：`词汇日.xlsx` 会读取**全部工作表**（Sheet1、Sheet2、Sheet3…），
> 只要格式与 Sheet1 相同即可，后续往新表里加词无需改任何设置。
> 同一个词出现在多张表里只收录一次（跨表去重）。
> `词汇英.xlsx` 按你的要求**只读 Sheet1**。

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 英语中文释义 | `词汇英.xlsx` C 列 | 原样使用，不改写 |
| 英语美式音标 | **CMUdict**（离线，126k 词） | ARPAbet → 美式 IPA |
| 日语中文释义 | 内置种子 + MyMemory 翻译（联网兜底） | 见下 |
| 日语声调（几型） | **Kanjium 声调库**（离线，124k 词） | 标准东京音 |

* **英语音标**：由 CMUdict 生成，重音符号按“最大音节首”原则定位，
  风格接近朗文/牛津美式标注，如 `conspiracy → /kənˈspɪrəsi/`
* **日语释义**：现有 226 个词已内置人工整理的释义；意思相近的词特意写得详细以便区分
  （如 `学生`（泛指在校读书）/ `生徒`（中小学学生）/ `児童`（小学儿童）/
  `幼児`（学龄前）/ `研究生` / `大学院生`）。日后新增的词按下面的顺序补全

  **新词释义的补全顺序**：内置词表 → **AI（DeepSeek）** → 免费翻译接口 → 留空待手工填写。
  AI 那一档需要配置一次 API key，见下。
* **日语声调**：来自 Kanjium 声调库，另有 10 个 Kanjium 未收录的词由补录表补齐，
  当前 226 个词覆盖 **211 个（93%）**。
  `する` 动词（如 `勉強する`）会退回其词干（`勉強`）的声调，
  计数器（`～時`/`～分` 等）按能查到读音时的结果给出。
  仍缺的 13 个多是寒暄语与专有名词（如 `ありがとうございます` 已补，`こちらこそ`、
  `分かりません`、`北京大学`、`大学院生` 等仍缺），会显示 **“声调待补”**，
  可在数据库页手动填写，填写后不会被自动覆盖

> ⚠️ `data/ja_accent.json`（补录表）的数据来源**没有许可证声明**，仅供你个人学习自用，
> **请勿分享或发布本项目**。详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

> 声调是标准东京音（共通語）。Kanjium 对同一个词可能给出多个可接受声调（如 `あなた` 为
> `2型・1型`），会一并显示。若与你的教材不同，请在数据库页以教材为准修改。

## 词表格式

程序读取桌面上的两个 xlsx；仓库 `data/` 下有同名示例文件，只是格式参考。
**桌面上的文件优先**——两者都存在时会用桌面那份。想确认程序实际读的是哪一份，
看【数据库】页顶部的「数据源」一行：用的是仓库示例表时会有红色提示。

### `词汇英.xlsx`（只读 Sheet1）

|   | A | B | C |
|---|---|---|---|
| 1 | 序号 | 单词 | 中文意思 |
| 2 | 1 | shrug | v.耸肩 |
| 3 | 2 | oblivious | adj.察觉不到，健忘的 |

* 只读 Sheet1，其余工作表忽略
* A 列序号可以省略，程序能自动识别
* 音标不用自己写，程序会用 CMUdict 自动补上

### `词汇日.xlsx`（读取**全部**工作表）

每 3 列为一组：前两列是（词, 假名读音），第三列留空作分隔。
可以横向铺开任意多组，纵向接着写：

|   | A | B | C | D | E | F |
|---|---|---|---|---|---|---|
| 1 | 中国人 | ちゅうごくじん |  | 本 | ほん |  |
| 2 | 日本人 | にほんじん |  | かばん |  |  |
| 3 | 学生 | がくせい |  | 鉛筆 | えんぴつ |  |

* 有汉字的写汉字，没有的写假名即可（如 `かばん`）
* 读音列可以留空——纯假名词、片假名词通常不需要
* Sheet2、Sheet3… 格式相同会一并读取；同一个词跨表只收录一次
* 中文释义和声调不用自己写，程序会自动补（见下）

## AI 补全设置（可选，用于以后新增的生词）

内置词表已经覆盖了你现在所有的词，**不配置也能正常用**。配置之后，
以后往 Excel 里加的新词会自动由 AI 生成释义，质量接近内置的。

1. 到 <https://platform.deepseek.com> 注册并创建一个 API key（需充值少量，几元钱够用很久）
2. 打开应用 →【数据库】→【AI 补全设置】，填入 key，点【测试连接】确认可用后保存
3. 保存后会立刻为缺释义的新词补全一次；之后每次启动应用也会自动补

* 默认接 DeepSeek（`https://api.deepseek.com/v1`，模型 `deepseek-chat`）。
  Base URL 和模型名都可以改，指向任何 OpenAI 兼容接口都行
* 提示词按你内置释义的风格写好了：简单词从简、**近义词才展开区分**、需要时用〔〕注语体
* 每批 25 个词，一次调用几分钱。API key 以**明文**保存在 `data/llm.json`，
  也可以用环境变量 `DEEPSEEK_API_KEY` 代替，不写进文件
* 不配置时自动退回免费翻译接口（质量一般），再不行就留空等你在数据库页手动填

## 关于源文件

`词汇英.xlsx` 和 `词汇日.xlsx` **始终以只读方式打开**（openpyxl `read_only=True`），
程序任何路径都不会写回这两个文件；每次启动同步后还会校验其修改时间与大小，
若在读取期间被外部改动会在主界面提示。

## 依赖

* Python 3.10 或更高（开发环境为 3.12，安装时请勾选 tcl/tk）
* `openpyxl`、`cmudict`、`pillow`：

  ```bash
  pip install openpyxl cmudict pillow
  ```

* 界面用标准库 `tkinter`，无需额外安装

首次运行前建议执行一次 `python fetch_data.py` 下载日语声调库
（Kanjium，CC BY-SA 4.0）。不下载也能用，只是日语声调会显示「声调待补」。

数据来源与许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
