# Trilingo — English & Japanese vocabulary trainer

A Windows desktop app plus an iOS-friendly PWA. It reads word lists from Excel,
builds a small daily quiz, and schedules every word you get wrong for review at
day+1 / +3 / +7 / +15 / +30. IPA for English and pitch accent for Japanese are
filled in automatically — your spreadsheet only needs the words themselves.

中文说明见下方 [中文文档](#中文文档)。

### Features

* **Daily quiz from Excel** — reads `词汇英.xlsx` / `词汇日.xlsx`; every sheet of
  the Japanese workbook is parsed.
* **Mistake book with spaced review** — a word you miss is re-tested on a fixed
  ladder and graduates after 30 clean days. The book is maintained **locally**,
  so it keeps working offline; sync only ever adds to it.
* **New Standard Japanese test bank** — 24 lessons / 1285 questions transcribed
  from the official workbook, three question types (fill-in, multiple choice,
  translation) with per-question timing, resume-from-where-you-stopped, and a
  full-paper review that marks mistakes in red.
* **Life log** — a small ledger (CNY / JPY / USD, kept separately) with a
  per-day income/expense bar chart and a monthly calendar, plus a daily
  "deer count" tracker.
* **Cross-device sync** — everything above (vocabulary progress, mistake book,
  test progress *and* life log) syncs through one private GitHub repo, free of
  charge, with a `sha`-based optimistic lock so two devices never clobber
  each other.
* **Crisp on HiDPI** — declares per-monitor DPI awareness, so text is rendered
  at physical pixels instead of being bitmap-stretched at 125 % / 150 %.

### Quick start

Requires Python 3.10+ with tcl/tk:

```bash
pip install openpyxl cmudict pillow
python fetch_data.py     # one-off: Japanese pitch-accent dictionary
python Trilingo.pyw
```

The phone version lives in `docs/` and is published with GitHub Pages; add it to
the iOS home screen for a full-screen, offline-capable app.

### Privacy

Nothing personal is committed to this repository. `trilingo.db` (all your
answers, ledger and deer records), `data/sync.json` (GitHub token) and
`data/llm.json` (API key) are git-ignored. Your data lives on your own devices
and in **your own private** GitHub repo used for sync.

# 中文文档

# Trilingo — 英语 / 日语 背单词

Windows 桌面应用。从 Excel 生词表读取词条，每日抽词测验；答错的词进入错题本，
按 day+1/+3/+7/+15/+30 的间隔自动排期复习。英语音标与日语释义、声调自动补全，
词表中只需填写词条本身。

## 运行

依赖 Python 3.10 或更高版本（安装时需勾选 tcl/tk）：

```bash
pip install openpyxl cmudict pillow
python fetch_data.py     # 下载日语声调库，执行一次即可
python Trilingo.pyw
```

* `fetch_data.py` 只需执行一次。未执行时程序仍可运行，仅日语声调显示「声调待补」
* `启动(调试).bat` 启动时保留控制台窗口，便于查看运行日志
* `create_shortcut.py` 在桌面创建快捷方式

## 功能

### 答题流程

1. 第一行显示中文意思
2. 第二行输入单词，回车提交
3. 第三行显示结果：
   * 拼写正确：显示音标（日语显示声调几型），5 秒后自动进入下一词
   * 拼写错误：显示正确拼写与音标，右下角出现【下一个】按钮，点击后继续；
     该词记入错题本

英语每日 7 个新词，日语每日 15 个新词，同一天不出现重复词条。

拼写判定：

* 英语忽略大小写、空格与连字符（`walkie-talkie` 与 `walkie talkie` 等效）
* 日语汉字形与假名读音均判为正确，片假名与平假名互通（`カメラ` 与 `かめら` 等效）

### 错题复习

| 事件 | 行为 |
| --- | --- |
| day0 答错 | 记入错题本，day+1 必现 |
| 复习答对 | 推进至下一档：+3 → +7 → +15 → +30 |
| 走完 +30 | 30 天内未再答错，移出错题本 |
| 中途再错 | 重置回 day0，重新排期 |

到期的错题必然出现在当日测验中（排在当日新词之后），主界面按钮显示待复习数量。

### 数据库页

以表格显示全部词条，英语/日语分页，支持点击表头排序与关键字检索。

* 选中一行后在下方修改，点【保存修改】写入；内容标记为人工，不会被自动补全覆盖
* 【重新读取 Excel】立即重新同步源文件
* 从 Excel 中删除的词标记为「已移除」并停止出题，历史记录保留

## 词表格式

程序读取桌面上的 `词汇英.xlsx` 与 `词汇日.xlsx`。仓库 `data/` 下有同名示例文件，
仅作格式参考。两处都存在时以桌面文件为准；【数据库】页顶部的「数据源」一行
显示程序当前实际读取的文件路径。

### 词汇英.xlsx（只读 Sheet1）

| A | B | C |
| --- | --- | --- |
| 序号 | 单词 | 中文意思 |
| 1 | shrug | v.耸肩 |
| 2 | oblivious | adj.察觉不到，健忘的 |

* 只读 Sheet1，其余工作表忽略
* A 列序号可省略
* 音标无需填写，程序自动补全

### 词汇日.xlsx（读取全部工作表）

每 3 列为一组，前两列是（词, 假名读音），第三列留空作分隔，可横向铺开多组：

| A | B | C | D | E |
| --- | --- | --- | --- | --- |
| 中国人 | ちゅうごくじん |  | 本 | ほん |
| 日本人 | にほんじん |  | かばん |  |
| 学生 | がくせい |  | 鉛筆 | えんぴつ |

* 有汉字的写汉字，无汉字的写假名
* 读音列可留空（假名词、片假名词通常不需要）
* Sheet2、Sheet3… 格式相同则一并读取，同一个词跨表只收录一次
* 中文释义与声调无需填写，程序自动补全

## 数据来源与自动补全

每次启动都会重新读取两个 xlsx，把新词并入数据库，并在后台补全缺失内容。

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 英语中文释义 | 词汇英.xlsx C 列 | 原样使用 |
| 英语美式音标 | CMUdict（离线，约 12.6 万条） | ARPAbet 转美式 IPA |
| 日语中文释义 | 内置词表 → AI → 免费翻译接口 | 逐级回退 |
| 日语声调 | Kanjium 声调库（离线，约 12.4 万条） | 标准东京音 |

**英语音标**由 CMUdict 生成，重音符号按最大音节首原则定位，
记音风格接近朗文、牛津的美式标注，例如 `conspiracy → /kənˈspɪrəsi/`。

**日语释义**优先查内置词表（`data/ja_seed.json`）。词表中意思相近的词条
特意写得较详细以便区分，例如 `学生`（泛指在校读书）、`生徒`（中小学学生）、
`児童`（小学儿童）、`幼児`（学龄前）。未收录的词按下列顺序补全：
内置词表 → AI（见下节）→ 免费翻译接口 → 留空。留空的词可在数据库页手动填写。

**日语声调**取自 Kanjium 声调库，为标准东京音。同一个词可能有多个可接受声调
（例如 `あなた` 为 `2型・1型`），会一并显示。`する` 动词回退到其词干的声调。
词库未收录的词显示「声调待补」，可在数据库页手动填写，填写后不会被自动覆盖。

## AI 补全设置（可选）

未配置时程序完全可用，仅新词释义退回免费翻译接口。配置后新增词条由 AI 生成释义。

1. 在 <https://platform.deepseek.com> 注册并创建 API key
2. 打开应用：【数据库】→【AI 补全设置】，填入 key，点【测试连接】确认后保存
3. 保存后立即补全一次，此后每次启动自动补全

* 默认接口为 DeepSeek（`https://api.deepseek.com`，模型 `deepseek-flash`）。
  Base URL 与模型名均可修改，兼容任何 OpenAI 格式接口
* 提示词按内置释义的风格设定：简单词从简，仅近义词展开区分，语体用〔〕标注
* 每批 25 个词。API key 以明文保存在 `data/llm.json`，
  也可改用环境变量 `DEEPSEEK_API_KEY` 而不写入文件
* 不配置时自动退回免费翻译接口

## 手机端（PWA）与跨设备同步

`docs/` 下是一份功能相同的网页版，可添加到 iPhone 主屏幕，像原生应用一样全屏运行，
离线也能背单词。它与电脑端共享进度：手机上完成今日训练，电脑端即显示已完成，反之亦然。

手机端与桌面端**功能对齐**：六个入口（英语词汇 / 日语词汇 / 错题本 / 新标日测试 /
句子练习 / 生活记录）都有，新标日测试用同一份 `minna_tests.json`、同一套三种题型的交互，
进度存在手机本地（`localStorage`），不上传。
**所有数据都参与跨设备同步**：单词学习进度（事件流）、错题本、新标日测试进度与
生活记录（账本 / 记鹿）都打包进同一个 state.json；其中账本按内容去重求并集、
记鹿按天取较新的一次、每课测试进度取更新时间较新的一份。

> 目录名叫 `docs` 是因为 **GitHub Pages 只允许从仓库根目录或 `/docs` 发布**，
> 不能指定任意文件夹。这是 GitHub 的约定，与本项目文档无关。

### 同步原理

数据存放在一个 **GitHub 私有仓库**的 `state.json` 中，两台设备各自「拉取 → 合并 → 回传」。

* **事件流而非快照**：每答一题追加一条 `{时间, 语言, 单词, 对错}`。合并就是按 id 求并集，
  因此一端先操作也不会覆盖掉另一端的记录
* **错题本是本机自维护的表，不靠推导**：每答一题**就地**更新错题本（答错重置 day0、
  答对推进一档、走完毕业），断网也完全正常。同步只做加法 —— 把对方的作答事件逐条叠加上来，
  绝不重建、绝不覆盖本机记录。早先的版本用云端快照覆盖本机错题本，导致「刚答对推进的档位
  被同步打回旧值、复习日退回过去」，所以那个架构已经废弃
* **每日抽词是确定性纯函数**：按 `fnv1a(日期|语言|单词)` 排序取前 N 个，
  两台设备算出的当日计划必然一致，计划本身无需同步
* **冲突处理**：**以电脑端为准**。错题本、打卡天数、每日进度、学习统计这些状态
  在两端不一致时采信电脑端；答题事件仍然取并集，所以手机上做的题不会被丢掉。
  提交时带 `sha` 作乐观锁，被另一端改过会返回 409，此时重新拉取合并再提交
* 无需服务器，无任何费用。纯文本 JSON，单次同步约几十 KB

### 一次性配置

1. 新建一个**私有**仓库存放数据，例如 `Trilingo-data`（建议勾选 Add a README 以初始化）
2. 生成访问令牌：GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token
   * Repository access 选 **Only select repositories**，只勾 `Trilingo-data`
   * Permissions → Repository permissions → **Contents** 设为 **Read and write**
   * 其余权限全部保持 No access
3. 电脑端：【同步】→ 填入令牌、用户名、数据仓库名 → 【测试连接】→【立即同步】
4. 手机端：安装 PWA 后，在【同步】页填入同样的三项 → 【立即同步】

> 令牌只保存在本机（`data/sync.json`，已 gitignore），不会上传到任何地方。
> 万一泄露，由于它是细粒度令牌且只对一个仓库有读写权，影响范围有限；仍应立即吊销重建。

## 新标日测试

把《新版中日交流标准日本语（初级上）同步测试卷》做成了 24 课的机考题库，共 **1285 道题**。
列表页每课一整行，从左到右：**第几课 · 完成进度(进度条) · 成绩 · 完成时间**。

三种题型对应三种交互：

| 题型 | 交互 |
|---|---|
| 填空（大题一、二） | 整题一次列出 10 小题 →【显示答案】逐列对齐显示 → 每题一个对/错按钮（默认"对"，按下即标错）→ 右下角【下一大题】 |
| 选择（大题三、四、五） | 一次一小屏，选项按钮；答对 5 秒后自动下一题，答错显示正确答案并给【下一题】 |
| 翻译（大题六、七） | 一次一小题，先看题 →【显示答案】→【对】【错】自评 |

* 进入一课开始计时，**中途可以退出**，位置与已判定的结果都会存下来，回来接着做
* 全部做完后停止计时，进入**整张试卷**：题干与答案并排，错题标红，滚轮上下翻看
* 已经做完的课，下次点开直接看试卷；想重来可以点【重做这一课】

> 题库由 `tools/build_minna_tests.py` 从 PDF 生成（`data/minna_tests.json`）。原 PDF 的字体
> 映射有缺陷，会把一些汉字提取成形近字，生成脚本里有一张**逐字渲染原页核对过**的修正表；
> 原卷本身缺第 1 课第四大题，第 24 课也没有答案 —— 后者由 `tools/fill_minna_answers.py`
> 调用 LLM 生成（仅供参考）。
>
> **版权**：题目原文版权归原出版方及编者所有，本项目仅作个人学习用途转录，
> 详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
>
> 校验脚本：`tools/verify_minna_tests.py`（题型与答案是否自洽）、
> `tools/check_pwa.py`（PWA 里引用的元素是否都存在）、
> `tools/test_minna_fallback.mjs`（私有题库回退逻辑，备用）。

## 生活记录

主界面右下角【生活记录】里有两项。数据存在本机 SQLite，并随 state.json
**跨设备同步**（账本求并集、记鹿按天取较新）。

### 记账

表单三行：第一行**收入**（收入来源 + 金额 + 提交），第二行**支出**（同理），
第三行是**总余额 / 总收入**与【账单明细】入口。

* 人民币、日元、美元**分开记账，互不换算**（没有汇率来源，换算只会引入假精度）；
  右上角切换当前币种，所有数字都按该币种显示
* 金额最多两位小数，同一天可以提交任意多笔
* 点右上角【日历】看每天收支：**净收入绿色、净支出红色**，并给出当月收支总额
* 【年视图】一屏 12 个格子，**每个月只显示一个数值**（当月结余），并给出全年合计；
  点某个月可以回到该月月视图
* 【账单明细】按月列出每一笔（精确到秒）与累计余额，底部是**一张**收支柱状图：
  * 横坐标是**最近 16 天**（day-15 … day0），单位为天
  * **绿柱向上 = 当日收入，红柱向下 = 当日支出**，横轴就是 0 线
  * 蓝色折线是**当日净值**（收入 − 支出）
  * 柱子与折线**共用左侧那一根金额轴**（本来就是同一个量纲，净值必然落在
    −最大支出 与 +最大收入 之间）
  * **鼠标移到某一天的区域**，那一格会高亮并浮出当天的 **收入 / 支出 / 净值** 三个数

### 记鹿

从左到右四个按钮 **0 / 1 / 2 / 3**，颜色分别是白、黄、橙、红。

* **记的是「昨天」按了几次** —— 今天填的是前一天的数据，页面会写明填的是哪一天
* 每天只能选一个按一次；再按同一天是**改掉当天已记的值**（一天只留一条记录）
* 记录**只能改、不能删** —— 没有任何清除或删除入口
* 右上角日历里每天的格子按对应按钮颜色上色并显示当天数值；日历**只作展示**，
  日期不可点击选择
* 底部统计**当月鹿次数**，即当月每天按下的数字之和
* 【年视图】一屏 12 个格子，每个月只显示当月鹿次数之和；点某个月回到该月月视图，
  也可以翻年份

程序首次运行后会生成 `trilingo.db`（SQLite 数据库，保存词条、错题、打卡记录与生活记录）
与 `trilingo.log`（运行日志）。

每次启动会在 `backups/` 下留一份数据库快照，保留最近 10 份。
练习数据一旦丢失无法从词表重建（错题本、打卡记录只存在于数据库中），
如需回退，把 `backups/` 里的文件复制回 `trilingo.db` 即可。

## 关于源文件

`词汇英.xlsx` 与 `词汇日.xlsx` 始终以只读方式打开（openpyxl `read_only=True`），
程序不会写回。每次同步后会校验其修改时间与大小，若在读取期间被外部改动会在主界面提示。
